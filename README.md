# 💼 Employee Salary Prediction

A machine learning web application that predicts employee salary class based on demographic and work-related attributes such as age, education, occupation, and hours worked per week. Built with Python and deployed as an interactive **Streamlit** app.

🔗 **Repository:** [RahulMahawar310/Employee-Salary-Prediction](https://github.com/RahulMahawar310/Employee-Salary-Prediction---Rahul-Mahawar)
🚀 **Live Demo:** [Try the app](https://employee-salary-prediction---rahul-mahawar-dekh3ay7n8cirs3aowa.streamlit.app)

---

## ✨ Features

- 🔍 **Real-time Salary Prediction** — Enter employee details and instantly get a predicted salary class
- 🧹 **End-to-End ML Pipeline** — Data cleaning, preprocessing, encoding, and feature scaling
- 📊 **Model Comparison** — Multiple ML algorithms trained and evaluated to select the best performer
- 🖥️ **Interactive Streamlit UI** — Simple, user-friendly interface for non-technical users
- ☁️ **Deployed on Streamlit Cloud** — Accessible from anywhere, no local setup required

## ⚙️ Getting Started

### Prerequisites

- Python 3.8+
- pip

### 1. Clone the repository

```bash
git clone https://github.com/RahulMahawar310/Employee-Salary-Prediction---Rahul-Mahawar.git
cd Employee-Salary-Prediction---Rahul-Mahawar
```

### 2. Install dependencies

It's recommended to use a virtual environment:

```bash
python -m venv venv
source venv/bin/activate   # On Windows: venv\Scripts\activate
pip install -r requirements.txt
```

### 3. Run the app

```bash
streamlit run app.py
```

The app will open automatically in your browser at `http://localhost:8501`.

---

## 🧠 How It Works

1. Raw employee data is cleaned — handling missing values, removing outliers, and encoding categorical features
2. Features are scaled and prepared for modeling
3. Multiple ML models are trained and compared on evaluation metrics (accuracy, precision, recall, etc.)
4. The best-performing model is saved and integrated into the Streamlit app
5. Users input employee attributes through the UI and receive an instant salary prediction
